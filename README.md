# Resume

This repository contains a resume source file and a template to create custom, ATS-optimized resumes.

How to use
- Create a branch from `custom_raksol_it` (done: `custom_raksol_it_jpm_resume`).
- Edit the template sections below to reflect your actual experience, numbers, and technologies.
- Emphasize the exact keywords and phrasing shown in the "ATS Keywords & Suggested Phrases" section.

## ATS Keywords & Suggested Phrases
Include these phrases verbatim where applicable (use in summary, skills, and experience bullets):

- "Experience in the preparation of Technical Design documents"
- "Can work independently and progress the build of a CEMLI/RICE object from a technical design document"
- "Hands on experience on Data Conversion/Migrations, Inbound / Outbound interfaces, Reports, Forms and Customizations"
- "Experience in Implementation and RICE Customizations of Oracle Applications 11i/R12"
- "Strong knowledge of Oracle Applications and proven expertise in Oracle Pl/SQL, Forms & Report and Workflow"
- "Expertise in Performance tuning"
- "Expertise in Oracle Forms (Development and Personalization), BI Publisher Reports, Oracle Workflows"
- "OAF experience will be preferable"
- "Sound knowledge in using Oracle APIs for interfaces to Oracle Financials and AOL/Sys-Admin components"

Suggested phrasing examples (copy/adapt these into your bullets):

- "Prepared Technical Design documents for [module], detailing data mappings, interfaces, and acceptance criteria."
- "Built CEMLI/RICE objects (Forms/Reports/Interfaces/Extensions) from technical design documents, working independently to deliver end-to-end solutions."
- "Executed data conversion/migration activities for [project], transforming and loading [N] records and validating results through reconciliation scripts."
- "Developed inbound/outbound interfaces using Oracle APIs and PL/SQL to integrate external systems with Oracle Financials."
- "Implemented RICE customizations in Oracle Applications 11i/R12 including Forms, Reports, Workflows and BI Publisher templates."
- "Performed PL/SQL and report performance tuning, reducing runtime/latency by [X]% through query and code optimizations."

Notes
- Keep the resume to 1–2 pages if possible.
- Mirror language from the JD in both the summary and key skills to improve ATS scoring.
- Replace bracketed placeholders with concrete details and metrics.
